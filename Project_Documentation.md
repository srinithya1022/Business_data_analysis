## 1. Introduction
This project is a simple business data analysis system developed using Python. It reads sales information from a CSV file, cleans the data, calculates sales values, analyzes products, categories and regions, and creates charts and a report.

## 2. Objectives
- Read business data from a CSV file.
- Check and clean the data.
- Calculate total sales and quantity sold.
- Analyze product, category and region performance.
- Visualize sales information.
- Generate a simple report.

## 3. Modules Used
- Pandas: data loading, cleaning and analysis.
- Matplotlib: chart creation.
- OS: creation of the charts folder.

## 4. Input
The input file is `sales_data.csv`.

## 5. Processing
Total sales for each record is calculated as:
Quantity × Price

The program then groups the data by product, category, region and month.

## 6. Output
The system generates a text report and two charts.
