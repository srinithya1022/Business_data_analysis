# Python-Based Business Data Analysis & Reporting System

## Objective
Analyze business sales data using Python and generate useful summaries, charts, and a text report.

## Technologies
- Python
- Pandas
- Matplotlib
- CSV

## How to run
1. Install Python.
2. Open a terminal in this project folder.
3. Install libraries:
   `pip install pandas matplotlib`
4. Run:
   `python main.py`

## Output
The program creates:
- `report.txt`
- `charts/sales_by_category.png`
- `charts/monthly_sales.png`
